# Change log

## [v1.1.0](https://github.com/simvue-io/connectors-moose/releases/tag/v1.1.0) - 2026-10-13

* Add load support
* Add support for selecting which files to upload as output Artifacts
* Improve tracking of Vector PostProcessors using 2D metrics
* Improve log handling
* Add support for static simulations
* Improve detection of parallel runner executables including srun
* Add option to upload miscellaneous log messages to the Events log
* Improve simulation initialization metadata by indenting under header
* Handle comments in input files
* Add support for multiple input files
* Add support for !include lines

## [v1.0.0](https://github.com/simvue-io/connectors-moose/releases/tag/v1.0.0) - 2025-03-07

* Initial release of MOOSE Connector.
